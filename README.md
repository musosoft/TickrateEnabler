# Tickrate Enabler

## How to use:
1. Get the latest release for your OS at: `https://github.com/musosoft/TickrateEnabler/tree/master/prebuilt/linux-x86_64`
2. Extract the archive to your game folder (For example: cstrike)
3. Add `-tickrate <number>` to your launch parameters
